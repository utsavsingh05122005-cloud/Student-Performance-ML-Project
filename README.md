# Student Performance ML Project

A Student Performance Prediction & Analysis System built as a learning project.

## Project Goal

The goal of this project is to understand how a complete Machine Learning application is built, from collecting and analyzing data to training a model and connecting it with a web application.

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Git and GitHub

## Project Stages

1. Project Planning
2. Python Basics

4. Dataset and Data Analysis
5. Data Visualization
6. Machine Learning Fundamentals
7. Model Training and Evaluation
8. Saving and Loading the Model
9. Flask Backend
10. Frontend
11. Database

13. Git and GitHub
14. Deployment
